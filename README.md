# Xaos Music Player

A music player for Android and Windows, designed after Nothing OS: black and white, dot-matrix type, a single red (or yellow) accent, and nothing that does not need to be there.

The phone app plays your local library. The desktop app is where the library lives: it plays it, edits it, and sends it to the phone over USB. Favorites, playlists and listening history stay in sync between the two.

**[Download the latest release](https://github.com/XaosWasHere/xaos-music-player/releases/latest)**

## Features

### Android

- Local library by songs, albums and artists, with search.
- Home with recently played albums, a monthly recap and a yearly "wrapped" you can export as an image.
- Albums, playlists and favorites open like on Spotify: large cover, details, then the tracks.
- Playlists with custom cover and a short description.
- Now playing screen with four backgrounds, including a dot-matrix glow that reacts to the music and the album art in full screen.
- Synced lyrics read from the files (ID3 USLT, LRC timestamps).
- Equalizer, bass boost, virtualizer, preamp and a sleep timer.
- Search and download from YouTube with yt-dlp, saved as tagged MP3 with cover art.
- Metadata editing inside the app, light and dark theme.

### Windows

- Library from one or more folders, grouped by album name, with FLAC and MP3 copies of the same song shown once.
- Duplicate finder that lists identical copies and moves them to the Recycle Bin on request.
- Player bar, full screen player with a waveform seek bar, and an always on top mini player.
- Lyrics panel that follows the song, lyrics editor with search on LRCLIB.
- Favorites, playlists with cover and description, listening stats by month, year or all time.
- Tag, cover and track order editing, written directly into the files.
- Search and download from YouTube; Xaos keeps its own yt-dlp up to date.
- Windows media controls: taskbar thumbnail buttons, the system media flyout and the keyboard media keys.
- Equalizer, output device choice, adjustable interface size, light and dark theme.
- Only one copy runs at a time.

### Sync over USB

Plug the phone in with USB debugging enabled and open the Phone screen.

- **Send to phone**: copies what the phone is missing, choosing per album or per track. Songs already on the phone are recognised by title, artist and duration, wherever they are and whatever they are called. Nothing is ever deleted.
- **Import from phone**: copies to the PC the music that only exists on the phone.
- **Lyrics**: lyrics added on the PC can be written into the phone's copies.
- **Favorites, playlists and listening history**: exchanged both ways at every connection. Each side keeps its own changes, and a playlist deleted on one side disappears from the other.
- **App install and updates**: the desktop app carries the Android app and offers to install or update it on the phone.

## Requirements

- **Windows** 10 or 11, 64 bit. VLC and adb are included. Downloads also need ffmpeg: `winget install Gyan.FFmpeg`.
- **Android** 7.0 or later on an arm64 phone. To sync, enable USB debugging in the developer options and allow the PC when the phone asks.

## Install

1. Run `Xaos-<version>-windows-setup.exe`. It replaces any previous version and keeps your library, favorites and playlists.
2. Connect the phone and open the Phone screen: Xaos offers to install the Android app. You can also install the APK from the release page directly.

When updating, update the desktop app first, then the phone from the Phone screen.

## Building from source

The repository has two Gradle projects: the Android app in the root, the desktop app in `desktop`.

```bash
# Android: debug APKs, one per ABI
./gradlew :app:assembleDebug

# Desktop: run it
cd desktop
./gradlew run

# Desktop: installer (needs JDK 21 with jpackage and Inno Setup 6.7)
./gradlew packageInstaller -PandroidApkDir=../app/build/outputs/apk/debug
```

Inno Setup can be installed with `winget install JRSoftware.InnoSetup`. The installer images are generated by `desktop/installer/make_images.py`.

## Built with

- Kotlin and Jetpack Compose on Android, with Media3 for playback.
- Kotlin and Compose Multiplatform on the desktop, with VLC (through vlcj) for playback and jaudiotagger for tags.
- adb for everything that happens on the phone, yt-dlp for downloads, LRCLIB for lyrics.
- A small C# bridge for the Windows media controls, and Inno Setup for the installer.

## Privacy

Everything stays on your devices. Xaos goes online only when you ask it to: searching and downloading music, searching lyrics on LRCLIB, and a single check at startup for a newer release on GitHub.

## Third party components

The desktop app includes parts of VLC (LGPL 2.1 or later) and adb from the Android SDK Platform-Tools (Apache 2.0). Details are in `THIRD-PARTY-NOTICES.txt`, next to the app after installation.
