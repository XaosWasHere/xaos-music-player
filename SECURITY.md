# Security Policy

## Supported Versions

Make sure to always update Xaos to the latest version, so any bug and vulnerability is fixed

| Version | Supported          |
| ------- | ------------------ |
| 1.4.x   | :white_check_mark: |
| 1.2     | :white_check_mark: |
| 1.1     | :x:                |
| 1.0     | :x:                |

## Reporting a Vulnerability

If you find a vulnerability, make sure to repoort it using the "issues" form, and I'll
try to fix it as fast as possible.
